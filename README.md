# Bank Recommendations Service

Микросервис для выдачи персональных банковских рекомендаций на основе анализа транзакций пользователя. Поддерживает статические и динамические правила, а также интеграцию с Telegram-ботом.

## 🛠 Стек технологий
* Java 17, Spring Boot 3.3.5
* PostgreSQL (JPA), H2 (JDBC)
* Liquibase, Caffeine Cache
* Swagger (OpenAPI 3)
* TelegramBots
